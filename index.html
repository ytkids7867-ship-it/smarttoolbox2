Frequently asked questions

Are these tools free?

Yes. SmartToolbox tools are free to use. Some tools rely on third-party browser libraries loaded from a CDN.

Do I need to create an account?

No account is required for the tools on this version of SmartToolbox.

Are my files uploaded?

File processing is performed in your browser for the tools on this page. Avoid using any online tool for confidential documents unless you have reviewed its privacy and security properties.

Can I use these tools on my phone?

Yes. The website is responsive and designed for mobile, tablet and desktop screens.
